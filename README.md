# Online Bookstore SQL Analysis

## Project Overview
This project analyzes an online bookstore database using MySQL. It explores books, customers, and orders to answer business questions about revenue, sales, customer purchasing behavior, and inventory.

## Database Tables
- **Books:** Book details, authors, genres, prices, and stock.
- **Customers:** Customer information and locations.
- **Orders:** Order dates, quantities, book IDs, customer IDs, and order amounts.

## Tools Used
- MySQL
- SQL
- CSV datasets

## SQL Concepts Practiced
- SELECT, WHERE, ORDER BY, DISTINCT
- Aggregate functions: SUM, AVG, COUNT
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries and COALESCE
- Business-focused data analysis

## Business Questions
1. What is the total revenue generated by orders?
2. Which book is the most expensive?
3. Which genres sell the most books?
4. Which customers have placed multiple orders?
5. Which customer has spent the most?
6. What is the average price of Fantasy books?
7. Which authors have sold the most books?
8. How can remaining book stock be calculated?

## Project Structure
- `Books.csv` — Books dataset
- `Customers.csv` — Customers dataset
- `Orders.csv` — Orders dataset
- `Books_Script.sql` — Books table script
- `Customers_Script.sql` — Customers table script
- `Orders_Script.sql` — Orders table script
- `Queries.sql` — Analysis queries

## How to Run
1. Install MySQL and open MySQL Workbench.
2. Create the `online_bookstore` database.
3. Import the three CSV files into their corresponding tables, ensuring the columns and data types match.
4. Open `Queries.sql`.
5. Run the queries and review the results.
